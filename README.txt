EONIX BOOKING — FRONTEND PROTOTYPE

1. Extract this ZIP.
2. Upload the eonix-booking/index.html file to your GitHub repository.
3. For GitHub Pages, publish from the branch/folder containing index.html.

Features:
- Responsive desktop and mobile layout
- Dark/light theme
- Dashboard overview and booking activity
- Create, search, filter and update bookings
- Monthly calendar
- Services, customers and staff management
- Availability, branches, resources, reviews, promotions, reports,
  subscription, notifications and settings screens
- CSV booking export
- Browser localStorage demo persistence

IMPORTANT:
This is a frontend-only prototype. It uses sample data stored in the
current browser. It does not include authentication, a server/database,
secure multi-user access, real notifications, online payments, or
production booking synchronization. Do not use real customer data until
a secure backend and access controls have been implemented.
